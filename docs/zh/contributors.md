## 审查、报告与测试

- [u/JesseWebDotCom](https://www.reddit.com/user/JesseWebDotCom)：在发布帖中发表了对 0.1.0 的安全审查。由此带来了 0.2.0 中对项目 `.env` 的修复（[#709](https://github.com/alexwkleung/reika/pull/709)），以及 [#706](https://github.com/alexwkleung/reika/issues/706)–[#708](https://github.com/alexwkleung/reika/issues/708) 中的沙箱加固。他们还在 M4 Pro 24GB 上将 Reika 与其他编程智能体（Aider、OpenCode、Codex CLI）做了对比。
- [u/Feisty-Ambassador215](https://www.reddit.com/user/Feisty-Ambassador215)：一份早期报告，介绍了在 Ornith 1.5 9B 上日常使用 Reika 的情况

## 加入名单

合并的 pull request 会在这里和[更新日志](../../CHANGELOG.md)中致谢。能改变 Reika 行为的报告和审查同样算数：[支持项目](support.md)列出了最有帮助的几种方式，在你的硬件上跑出的结果可以分享到[测试者 issue](https://github.com/alexwkleung/reika/issues/791)。无论大小，任何贡献都欢迎。
