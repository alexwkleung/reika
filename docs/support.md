# Support

[← README](../README.md)

Reika is free and open source under the [Apache 2.0 license](../LICENSE), built and maintained by one
independent developer. There is no paid tier, no hosted service and no license key, and none is
planned. Nothing about using it changes if you never pay for it.

## Funding

If Reika is useful to you and you'd like to help keep it going, any of these works, once or
recurring:

- [GitHub Sponsors](https://github.com/sponsors/alexwkleung)
- [Ko-fi](https://ko-fi.com/alexwkleung)
- [Buy Me a Coffee](https://buymeacoffee.com/alexwkleung)

Sponsorship pays for time spent on Reika and local hardware upgrades. It comes with no obligations either way.

## Using Reika at work

There is no commercial edition, support contract or enterprise license to buy, and none is needed:
Apache 2.0 already allows commercial use. If your team relies on Reika and wants to support it,
GitHub Sponsors accepts sponsorships from organizations as well as from individuals.

## Other ways to help

- **Report what broke.** A bug report with the steps to reproduce it, the model and the inference
  engine is worth more than most patches. The [issue template](../.github/ISSUE_TEMPLATE/issue.md)
  asks for exactly that.
- **Share a run on a model that isn't listed.** [Tested models](models.md) is built from real runs,
  and what worked or failed on a model nobody has tried yet is useful either way.
- **Contribute.** Start with [CONTRIBUTING.md](../CONTRIBUTING.md), which covers setup, conventions
  and what makes a change easy to accept.
- **Tell someone.** A star, or mentioning it to someone running models locally, is how people find it.

## Contact

- **Questions, ideas and model reports:** [GitHub Discussions](https://github.com/alexwkleung/reika/discussions),
  where the answer helps the next person too.
